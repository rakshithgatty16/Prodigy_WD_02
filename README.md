# Prodigy_WD_02 - Stopwatch Web Application

## Project Overview

This project is a Creative Stopwatch Web Application developed using HTML, CSS, and JavaScript. The application allows users to accurately measure time intervals with features such as start, pause, reset, and lap time recording.

The project focuses on creating a modern, interactive, and user-friendly stopwatch with an attractive user interface.

## Features

- Start Stopwatch
- Pause Stopwatch
- Reset Stopwatch
- Responsive Design
- Easy-to-Use Interface

## Technologies Used

- HTML
- CSS
- JavaScript
